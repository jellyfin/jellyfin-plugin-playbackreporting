My statistics page

Every user gets a "My statistics" entry in the avatar menu. Jellystics links itself automatically (URL and secret pushed on sync); the page is relayed by this plugin, so Jellystics only needs to be reachable from the Jellyfin server.

Purge plays before

Permanently deletes the closed plays that started before the chosen date. The purge is local to the plugin: it is not propagated to Jellystics, and importing Playback Reporting again restores the purged rows that come from it.
